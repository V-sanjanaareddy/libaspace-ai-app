# Libaspace AI App Submission

## Description
This project demonstrates a real-time digital human avatar that speaks text input in real time. 

## Setup Instructions

### Backend
1. Navigate to `backend` folder
2. Install dependencies: `npm install`
3. Start server: `npm run dev`
4. Server runs on `http://localhost:4000`

### Frontend
1. Navigate to `frontend\web` folder
2. Install dependencies: `npm install`
3. Start frontend: `npm run dev`
4. Open browser at `http://localhost:3000`

### Usage
1. Type any text in the input field
2. Click **Speak**
3. The avatar will display the text and “speak” it in real time

## Notes
- Currently, the avatar echoes the input text (proof-of-concept)
- Ready for AI TTS integration (Tavus Persona API / LiveKit)
